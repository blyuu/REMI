# Phase 8 — 중력 반전 게임을 엔진 위에 올리기

> v0.8.0 당시 로그임. 지금 보이는 Quinn·코인·HUD는 이후 버전에서 추가했으므로 이 단계의 성과로 섞지 않았음.

## 만들려고 한 플레이

작은 3D 레벨이라도 시작→조작→실패→재시작→도착이 모두 돌아가야 엔진의 입력·물리·렌더링 연결을 검증할 수 있다고 봤음. 좌우 발판 사이의 틈을 천장으로 우회하고 목표로 내려오는 한 경로를 만들었음.

## 분리한 부분

- `GravityGame`은 입력 장치나 Renderer를 직접 받지 않고 `Controls`와 고정 dt를 받게 했음. Scene·PhysicsWorld를 조합해 레벨과 승패만 관리함. 엔진에는 출구 위치와 코인 같은 게임 규칙을 넣지 않았음.
- WASD는 월드 XZ 방향, 이동 속도는 4 units/s로 뒀음. 대각선 입력을 정규화하고 공중 이동은 허용했음. `Space`는 접지 시에만 중력 상하를 반전시키며, 반전할 때 수직 속도를 0으로 초기화함.
- 완료 조건은 출구 근처 위치, 아래 방향 중력, 접지, 낮은 중심 높이를 모두 만족해야 했음. 천장에서 출구 위를 지나기만 하면 완료되지 않게 했음.
- Restart는 새 Scene/PhysicsWorld를 완성한 뒤 교체하도록 했음. 오래된 Scene ID가 다음 게임의 객체를 가리키지 않게 하려는 선택이었음.

## 검증했음

당시 Debug/Release 각각 13개 테스트와 CPU ASan 6개 테스트가 통과했음. 틈에서 추락, 천장 안착, 두 번째 반전 뒤 목표 도착, 공중 반전 거부, 100회 Restart와 오래된 ID 거부를 확인했음. WARP와 RTX 4070 Laptop GPU에서 자동 승리 경로가 재현됐고 해당 실행의 GPU 종료 경고·잔존 child는 0이었음. 기록은 로컬 `versions/phase-08/`에 있음.

이 단계의 플레이어는 단일 박스였고 상태 표시는 창 제목이었음. 캐릭터 애니메이션·화면 HUD·코인·게임패드·레벨 파일·카메라 충돌은 아직 없었음. 이후 데모에서 추가된 기능과 구분해 둠.
