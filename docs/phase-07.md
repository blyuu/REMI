# Phase 7 — 공통 AABB 물리

## 왜 엔진 모듈로 뺐음

중력 반전 게임을 만들기 전에 낙하·충돌·접지를 게임 코드에서 분리하고 싶었음. 그래서 `PhysicsWorld`는 Scene을 비소유 참조하고, 게임의 승패나 입력은 알지 못하게 했음. 물리 위치는 Scene Transform에, 속도와 본체 설정은 PhysicsWorld에 둠.

## 계산 규칙

1. 삭제된 EntityId를 정리하고 Transform을 검증함.
2. `v += gravity × dt`의 semi-implicit Euler로 속도와 위치를 갱신함.
3. 정적 AABB에 대해 축별 이동 경로를 검사하고, 겹침은 8회 반복 보정함.
4. 마지막 접촉을 저장하고 현재 중력 반대 방향의 접촉으로 `Supported`를 판정함.

고정 tick은 Runtime의 1/60초를 사용했음. 중력은 아래·위·옆 방향으로 바꿀 수 있고, 바꾸는 순간 이전 접촉은 지움. 콜라이더는 회전 없는 월드 축 정렬 박스이며 시각적 scale과 반높이는 별개임. 부모가 있거나 회전한 Transform은 명시적으로 거부했음.

## 실제로 검증했음

Debug/Release 각각 11개, CPU ASan 5개 테스트가 통과했음. 자유낙하 60 tick에서 y 속도 -9.81·위치 -4.98675, 바닥·천장 접지, 1 tick의 고속 벽 충돌, 옆 방향 중력, 삭제된 엔티티와 슬롯 재사용을 검사했음. 수치 오차 허용은 .001이었음. 당시 결과는 로컬 `versions/phase-07/`에 보관했음.

이 물리는 액션 게임용 완성형 강체 솔버가 아님. 전체 쌍 검사 O(n²), 동적 본체의 이산 충돌, 마찰·반발·회전·캡슐·조인트 없음이 남았음. 화면에 보이는 모든 Mesh가 자동으로 물리 본체가 되는 것도 아님. 게임이 필요한 물체만 등록함.
